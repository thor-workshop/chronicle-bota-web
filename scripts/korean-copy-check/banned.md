# 금지 표현 사전

실제로 지적받은 것만 올린다. 새로 걸리면 여기에 추가한다.

## 조사·구문 번역투

| 금지 | 무엇의 직역인가 | 대신 |
|---|---|---|
| `~에 대해`, `~에 대한` | about / regarding | 목적격 조사로 붙인다. `이 문제에 대해 논의` → `이 문제를 논의` |
| `~를 통해` | through / via | `로`, `으로`. 또는 문장을 다시 쓴다 |
| `~에 있어서` | in terms of | 통째로 지운다 |
| `~와 관련하여` | in relation to | `~의`, `~에서` |
| `~되어진다`, `~지게 된다` | 이중 피동 | 능동으로 |
| `~에 의해` | by (수동태) | 능동으로 뒤집는다 |
| `~을 위해` 남발 | in order to | `~하려고`, `~하도록` |

## 낱말

| 금지 | 무엇의 직역인가 | 대신 |
|---|---|---|
| `당신`, `당신의` | you / your | 주어를 비운다. 소유가 꼭 필요하면 `내` |
| `들고 있다` | hold / carry | 담다, 남기다, 있다, 보관하다 |
| `제 색`, `제 소스`, `제 자리` | its own | `그 기종의`, `그`, 또는 생략 |
| `앞에 떠 있다` | in the foreground | `화면에 떠 있다` |
| `적대적인 것으로 취급` | treat as hostile | `의심하고 다룬다` |
| `경로 빠져나가기` | path traversal | `폴더 밖으로 새는 경로` |
| `~을 다닙니다` | navigate | `~을 움직입니다`, `~을 오갑니다` |
| `~을 셉니다` (목적어 없이) | count | `~을 기록합니다`, `~에 남습니다` |
| `~으로 셉니다` (분류하다는 뜻으로) | count as | `~으로 잡습니다`, `~으로 봅니다`, `~으로 다룹니다` |
| `자릿수` (규모의 뜻으로) | order of magnitude | `비슷한 크기`, `같은 수준` |
| `줄이 스스로 걷다` | 사물 주어(the line walks) | 걷는 사람을 주어로 세운다. `혼령들이 제 발로 걷기 시작했다` |
| `서사시 사다리`, `난이도 사다리` | ladder (단계를 하나씩 오르는 차례) | 비유를 풀어 쓴다. `서사시 단계가 열리는 차례`, `다음 단계가 열리는 조건` |
| `별 하나가 꺼졌다` | a star went out | 하늘의 별에 일어난 일은 `별 하나가 떨어졌다`. 꺼진 별(이미 빛을 잃은 별)이라는 이름은 써도 된다 |
| `망원경이 ~을 겨누자` | aim at | 망원경은 `바라본다`. 겨누는 것은 무기다 |
| `쿨타임을 끝낸다` | end the cooldown | `쿨타임을 초기화한다`, `바로 다시 쓸 수 있다` |
| `명중 시`, `피격 후` | on hit / after being hit | `맞으면`, `맞힌 적`, `맞은 뒤` |
| `한 번의 기도로` (한 번의 N으로) | with a single N | `기도 한 번에` |
| `~라고 알려진` | known as | `~라는`, `~다는` |
| `하나의 무기` (하나의 N) | a single N | 수를 세는 뜻이 아니면 `하나의`를 지운다 |
| 알림의 명사 쌓기 (`보스 방어 증가`, `회복 구슬 획득 불가`) | 영어식 표제 | 짧은 문장으로 쓴다. `프톨이 단단해진다`, `회복 구슬을 줍지 못한다` |

## 문장 만들기

| 금지 | 무엇의 직역인가 | 대신 |
|---|---|---|
| `~것입니다`, `~것이라`, `~한 것이고` | 명사화 | 서술어로 푼다 |
| 무생물 주어 | `the script fails the build` | 사람을 주어로 하거나 문장을 지운다 |
| 부정 종결 연발 | does not / never | 핵심만 남기고 나머지는 긍정으로 |
| `~뿐입니다` 연발 | only | 한 문단에 한 번까지 |

## 문장부호

| 금지 | 무엇의 직역인가 | 대신 |
|---|---|---|
| 문장 안의 가운뎃점 `·` | 영어 쉼표 목록 | 쉼표. 넷 이상이면 줄을 나눈다. 짧은 꼬리표(`iOS · Android`)에만 남긴다 |
| 줄표 `—` | em dash | 마침표로 끊거나 조사로 잇는다 |
| 괄호 안 부연 남발 | parenthetical | 문장을 나눈다 |

## 제목

| 금지 | 예 | 대신 |
|---|---|---|
| 문장형 제목 | `여기까지입니다`, `보내는 곳이 없습니다` | `지원하지 않는 기종`, `개인정보` |
| 의문형 제목 | `무엇을 할 수 있나` | `주요 기능` |
| 대구 제목 | `글꼴은 하나, 굵기도 하나` | `픽셀 글꼴` |
| 은유 제목 | `열한 대의 기계`, `한 장도 사다 쓰지 않았습니다` | `지원 기종`, `픽셀 디자인` |

## 문맥을 봐야 하는 것

기계 검사에 넣지 않는다. 문맥에 따라 옳은 문장이 되기 때문이다. 사람이 읽을 때 본다.

| 걸린 자리 | 무엇의 직역인가 | 대신 |
|---|---|---|
| `목록을 돌립니다` | runs the list | 무엇이 되는지로 다시 쓴다 |
| `쉴 때는` (버튼이 눌리지 않은 상태) | at rest | `누르기 전에는` |
| `색깔별로 붙습니다` | 무엇이 색깔별인지 밝히지 않음 | `기종 색깔로` |
| `있으면 하는 기능` | 문장이 무너짐 | `있었으면 하는 기능` |
| `제공합니다`, `경험`, `최적화` 남발 | provide / experience / optimized | 구체 동사로 바꾼다 |

2026-09-14에 걸린 것. 옷과 장비를 영어로 불렀다.

| 금지 | 무엇의 직역인가 | 대신 |
|---|---|---|
| `하네스` | harness | 멜빵, 가슴끈. 등산·구조 장비만 예외 |
| `패널` | panel | 천이면 자락, 판이면 판 |
| `파우치` | pouch | 주머니 |
| `키트` | kit | 가방, 꾸러미 |
| `로프` | rope | 밧줄 |
| `작은 포인트가 된다` | accent | 눈에 띈다 |

**만든 방법을 설명하는 문장을 넣지 않는다.** 읽는 사람은 결과를 본다. 어떤 한계가
있었는지, 무엇으로 그렸는지는 알 바가 아니다.

| 금지 | 왜 | 대신 |
|---|---|---|
| `선은 직선 연결이다` | 도구의 한계를 변명한다 | 지운다 |
| `실제 길은 아래 구글 지도에서 본다` | 링크가 이미 아래 있다 | 지운다 |
| `간판 색은 낮에 찍어야 제대로 나온다` | 근거 없는 단정 | 지운다 |
| `짐을 맡겼으니 어디든 간다` | 앞줄을 되풀이한다 | 지운다 |
| `19시에서 21시 사이에서 갈린다` | 갈리다를 이렇게 쓰지 않는다 | `날짜마다 다르다` |
| `현장 통신에 걸려 있으니` | 무엇이 걸렸는지 불명 | `현장에서 앱으로 잡으니` |
| `수고했다` | 도구가 사람을 치하한다 | 지운다 |
| `관객은 아직 안 왔고, 월요일이다` | 나열이 무너진다 | 문장을 끊는다 |

**목록 아래 요약을 붙이지 않는다.** 지도에 순서가 그려져 있으면 그 순서를 글로 다시
쓰지 않는다. `한 바퀴 돌고 숙소로 돌아와 짐을 찾는다`는 지도가 이미 말하고 있다.
